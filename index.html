Build websites faster with reusable components and a simple templating system designed for HTML developers.

Get Started Free
<require template='template_A.htt' />

  <h1>Hello World!</h1>

Make your own Templates - .htt files!

Put your HTML blocks into separate files with .htt extension and reuse them.

[PackageName]
// Silenced, can be accessed only by other templates
~ template_A.htt [PackageName]

// Usual import
+ template_B.htt [HelloWorld]

// Permanent exclusion
! template_C.htt []

Build your own template packages!

Create a .http file and store links to all your templates. Use package file to import and use all the templates.

user@host:~$ iguana project.html index.html

Compile templates into single file!

Use our open-source iguana interpreter written in Go to compile your file with templates into regular HTML file.
